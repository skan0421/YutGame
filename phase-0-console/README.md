# 윷놀이 게임 (콘솔 버전)

순수 자바로 구현한 2인용 윷놀이 게임입니다.

## 파일 구조

```
src/
└── com/
    └── yutgame/
        ├── Main.java                   # 게임 실행
        ├── domain/                     # 도메인 로직
        │   ├── Game.java              # 게임 메인 로직
        │   ├── Board.java             # 윷판
        │   ├── Player.java            # 플레이어
        │   ├── Piece.java             # 말
        │   ├── Position.java          # 위치
        │   ├── YutResult.java         # 윷 결과
        │   └── MoveResult.java        # 이동 결과
        └── console/                    # 콘솔 UI
            ├── ConsoleUI.java         # 출력
            └── InputHandler.java      # 입력
```

## 컴파일 방법

### 방법 1: 커맨드라인

```bash
# 컴파일
javac -d bin -sourcepath src src/com/yutgame/Main.java src/com/yutgame/domain/*.java src/com/yutgame/console/*.java

# 실행
java -cp bin com.yutgame.Main
```

### 방법 2: IntelliJ IDEA

1. IntelliJ에서 프로젝트 열기
2. `src` 폴더를 Source Root로 설정
3. `Main.java` 우클릭 → Run 'Main.main()'

## 게임 규칙

### 기본 규칙
- 2명의 플레이어가 각각 4개의 말을 가짐
- 윷을 던져 나온 결과만큼 말을 이동
- 모든 말을 먼저 도착시키는 사람이 승리

### 윷 결과
- **빽도** (-1칸): 뒤로 1칸
- **도** (1칸): 앞으로 1칸
- **개** (2칸): 앞으로 2칸
- **걸** (3칸): 앞으로 3칸
- **윷** (4칸): 앞으로 4칸, **한 번 더**
- **모** (5칸): 앞으로 5칸, **한 번 더**

### 특수 규칙
1. **잡기**: 상대 말이 있는 위치에 도착하면 상대 말을 시작점으로 보냄 → **한 번 더**
2. **쌓기**: 내 말이 있는 위치에 도착하면 말이 겹침 → 함께 이동
3. **지름길**: 특정 위치(5, 10, 22번)에서 대각선/중앙 경로로 이동 가능
4. **한 번 더**: 윷, 모, 잡기 성공 시 연속으로 윷을 던질 수 있음

## 플레이 방법

1. 프로그램 실행
2. 두 플레이어의 이름 입력
3. 턴마다:
   - Enter를 눌러 윷 던지기
   - 이동할 말 번호 선택 (1-4)
   - 결과 확인
4. 한 플레이어의 모든 말이 도착하면 게임 종료

```

턴: 5

  말4: 위치=0

  친구 (도착: 0/4)
  말1: 위치=5 (×2)
  말2: 도착!
  말3: 위치=0
  말4: 위치=0

현재 턴: 우주
==================================================

>>> [Enter]를 눌러 윷을 던지세요...

윷 결과: 윷 (4칸)
>>> 윷! 한 번 더 던질 수 있습니다! <<<
==================================================

이동 가능한 말:
[1] 말1: 위치=3
[2] 말2: 시작 위치
[3] 말3: 시작 위치
[4] 말4: 시작 위치

이동할 말 번호 (1-4): 1

이동 완료: 위치7
```
